# Release notes: buyer path, tools and demo library (10 Oct 2026)

**Branch:** `growth/offer-homepage-2026-10-10`, seven code commits on `main` at `cbb6c1c`, plus docs.

**Status: not released.** Merging to `main` deploys to www.pgak.co.in and needs the owner's explicit OK.

## What a visitor will see

1. **Homepage, rebuilt in the brief's order.**
   - Hero: "Make your existing CCTV more useful to your business", with **Check my cameras** and **See PGAK demonstrations**.
   - Then:
     - the recorded demonstrations;
     - five problem cards (perimeter, gate, counting, attendance, upgrade);
     - a four-step "How it works" diagram;
     - an in-page value estimator (six tasks);
     - the evaluation steps (what PGAK supplies, what you supply);
     - how pricing is structured (no numbers);
     - operating details;
     - an eight-question FAQ;
     - the assessment form.
   - The hero video is removed, so less weight loads above the fold.
2. **Compatibility check.** Three verdicts: *Known tested*, *Needs verification* and *Not suitable as it stands*. An optional make/model box is never sent. The tested list is empty, so no model is called "Known tested" yet.
3. **Scope builder** on `/resources/scope-worksheet`. It prints what a quote must itemise and what stays unknown. No price is shown.
4. **Demo library** on `/resources/evidence`. Filter by task. Each recording now says what to watch, what it shows, which calculator fits and the next step.
5. **Calculators.**
   - Every input has a "Source" (my estimate, records, pilot, written quote, worked example). It is exported in the CSV and summarised under the result.
   - The matching workflow diagram appears above six of the calculators.
6. **Storage article.** The retention calculator is built into `/insights/cctv-storage-how-many-days`.
7. **Redirects (308).**
   - `/evidence` → `/resources/evidence`.
   - `/trust/videos` and `/trust/photos` → `/resources/evidence`. These were unlinked placeholders.
8. **Enquiries remember the calculator.** An enquiry now carries the calculator a visitor used earlier in the visit (id only, for example `C09`).

## Rollback

Choose either:
- **Vercel → Deployments → the previous production deployment → "Promote to Production".** Instant; no git change.
- Or `git revert -m 1 <merge commit>` on `main` and push. Vercel redeploys the previous code.

Nothing in this release writes data or changes a URL's canonical, so rolling back loses nothing. The redirects simply stop.
